# Ruth — Fluent Book-Level QA

**Ruth 1–4: QA approved for the Fluent development branch.**

The book contains 85 canonical verses: 22 + 23 + 18 + 22.

## Frozen book-level lexical decisions
- **ḥesed → steadfast love** in 1:8, 2:20, 3:10.
- **go'el / ga'al / ge'ullah → redeemer / redeem / redemption**.
- Preserve **rest** across 1:9, 3:1, 3:18.
- Preserve **man of standing / woman of standing** in 2:1 and 3:11.
- Preserve **empty / empty-handed / restore life** across 1:21, 3:17, 4:15.
- Preserve meaningful **return** repetition.

## Resolved F3 decisions
- Ruth 1:15 — keep **her gods**.
- Ruth 1:20–21 — use **the Almighty** in Fluent; retain **Shaddai** in Vocabulary.
- Ruth 3:16 — keep **How did it go, my daughter?**
- Ruth 4:1 — keep **so-and-so**.
- Ruth 4:16 — use **held him close, and cared for him**.

## Apparatus revisions
- Ruth 1 receives canonical TSW Notes/Vocabulary, with ḥesed wording made translation-neutral.
- Ruth 2:3 no longer states providence as narrator-explicit.
- Ruth 3:9 distinguishes the explicit garment/redeemer request from its marital implication.

The book remains **not published** until this QA commit is pushed and the Ruth branch is merged to `main`.
