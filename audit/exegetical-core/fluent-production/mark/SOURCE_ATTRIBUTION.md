# Mark Source Attribution

The Fluent Mark production workflow uses the Greek text of the **SBL Greek New Testament (SBLGNT)** from the Faithlife/SBLGNT repository as its pinned machine-readable New Testament source.

- Repository: `Faithlife/SBLGNT`
- Pinned commit: `c4d241a9c1c479a55b989ba35a4976c1d0b8052c`
- File: `data/sblgnt/text/Mark.txt`
- License: Creative Commons Attribution 4.0 (CC BY 4.0)

The installer retrieves the file from the immutable commit and records a SHA-256 digest plus a SHA-256 binding for each included source verse. It does not silently fall back to an unpinned source.
