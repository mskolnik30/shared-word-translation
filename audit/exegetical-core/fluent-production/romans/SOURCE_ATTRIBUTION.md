The canonical **The Shared Word (TSW)** chapter files on repository `main` are used as project
comparators and apparatus resources. They are not Fluent's primary translation source.

Deployment validation must bind every included Fluent public verse label to the exact pinned
SBLGNT source record and record the corresponding canonical TSW chapter blob SHA.

## Romans 16 ending

The pinned SBLGNT `Rom.txt` contains **430 verse records**. Its final source record is Romans 16:24,
the grace benediction. The file does not contain source records for public Romans 16:25–27.
The familiar doxology is documented in the SBLGNT apparatus and has a complex placement history,
but it is not part of this package's pinned SBLGNT main text.
