# Companion Resources

The Shared Word Project maintains two distinct companion experiences around the same biblical canon:

- **Fluent Companion** supports orientation, sustained reading, formation, prayer, and biblical fluency.
- **TSW Study Companion** supports close attention to language, contested interpretation, reception history, power, harm, and shared discernment.

Neither companion is a third translation. A companion is a public reading layer attached to a passage in TSW or Fluent. People, places, maps, timelines, artifacts, and reusable images belong in the translation-neutral `resources/biblical-world/` layer and are referenced by both companions.

The machine-readable resource contract is in `registry.json`.
