# Translation Philosophy

This document outlines the guiding principles, translation rules, and theological commitments of The Shared Word Translation.

Content will be added incrementally as the project develops.

Notes in The Shared Word are text-anchored rather than commentary-anchored.
Greek appears only when it clarifies meaning, ambiguity, or translation choice.
When Greek is included, it is shown in Greek script with Roman transliteration.
Notes serve proclamation, study, and prayer — not scholarly exhaustiveness.
